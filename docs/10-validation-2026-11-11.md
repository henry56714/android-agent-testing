## 4. 自测中完成的修正

- 用例版本只绑定测试契约、测试脚本和测试资源；业务源码由 source fingerprint 追踪，允许同一测试版本比较修复前后。
- 测试前移动旧报告，防止读取上次的 XML 造成假通过。
- 检查目标 selector 实际出现、JUnit 声明条数与实际条数匹配；进程退出 0 本身不能作为通过依据。
- ADB instrumentation 必须有已完成的目标测试和终止 OK 信息；仅 ADB 退出成功不足以判定通过。
- 安装前复制 APK 到本次运行目录，检查哈希，使用该固定副本安装。
- 运行结束 force-stop 本次安装的 App/test 包，避免取消后设备测试继续运行。
- 资产路径统一为 root 相对路径，防止绝对路径或规范化路径破坏快照目录结构。

## 5. 尚未满足的发布条件

尚未实现目录写入事务 API、跨 clone 全局 revision 注册、完整源码快照恢复、自动 fixture/动态 helper 依赖分析、日志脱敏/保留期自动化、自定义能力插件和设备全局状态恢复。
