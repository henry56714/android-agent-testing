## 6. 私有项目试点

实际接入一个多模块 SDK/AAR + 宿主工程，新增 11 组持久化用例，不修改通用核心适配业务包名。修复其旧测试调用过期 API 的编译问题，强化真实 worker 替换和最大线程数断言；业务实现未改变。

- API 35 全量：10 组通过、1 组 SDK Lint 失败；本地 JVM 共 40 方法通过。
- API 33 动态：JNI 加载、SDK 生命周期、真实 Watchdog、UI 共四组通过。
- Watchdog 使用真实 30 秒轮询、自定义短任务超时，约 30 秒完成替换，校验业务池独立、后续任务执行与旧 worker 最终退出。
- UI 连续 10 次：4 PASS、6 次返回前台后的可见性断言不通过。截图出现白屏和键盘，根因未定，不能将其描述为稳定通过。第 5–8 次旧解析器输出 ERROR，第 9–10 次修正后输出 FAIL，均返回非零。
- SDK Lint 保留两项实际问题：高版本非 SDK 接口访问风险、库 manifest 精确定位权限缺少配套粗略定位声明。
